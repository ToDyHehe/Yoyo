# Био для соцсетей

Главное правило: **в каждом био — что рисуешь + что комишки открыты + одна ссылка.**
Для одной ссылки сделай бесплатную страницу на **Linktree / Carrd** со всем сразу (прайс, ToS, VGen, Ko-fi, соцсети).

Ники сейчас разные (`_todyhey`, `tody_whatever`, `_ToDyWhatever`). Идеально — один ник везде, например **ToDyWhatever**. Не обязательно, но людям проще тебя найти.

---
