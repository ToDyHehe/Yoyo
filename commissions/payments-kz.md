# Как получать доллары из Казахстана

_Проверено по открытым источникам в ноябре 2026. Правила платёжек меняются — перепроверь в своём аккаунте._

## Главный способ — PayPal

PayPal в Казахстане официально умеет **отправлять, получать и выводить** деньги. Вывод — на карту **Visa или Mastercard**.

**Что сделать:**
1. Зарегистрируй PayPal со страной **Kazakhstan** на свои настоящие данные (как в удостоверении).
2. Сделай **Business account** (бесплатно) — в нём есть **Invoices** (счета).
3. Привяжи Visa/Mastercard казахстанского банка и подтверди её.
4. **Проверь вывод до первого заказа:** попроси друга прислать $1–2, выведи на карту. Убедись, что доходит.
5. Если твоя карта не подходит для вывода — попробуй карту другого банка.

**Как брать оплату:** только через **Invoice** (счёт). Это «Goods & Services»: комиссия есть, но клиента и тебя защищает PayPal, и это не нарушает правила.
❌ Не бери оплату через **Friends & Family** за работу — PayPal может заблокировать аккаунт, а ты остаёшься без защиты.

**Комиссии:** PayPal берёт процент с каждого платежа + фиксированную сумму за вывод на карту + конвертация валюты. Точные цифры — на странице комиссий PayPal для Казахстана. Закладывай **~7–10% потерь** в сумме, цены в прайсе это учитывают.

## Площадки для комишек

### VGen ⭐ (рекомендую)
- Сайт специально для коммишенов, там клиенты **сами ищут** художников.
- Казахстан поддерживается, выплаты для KZ — **через PayPal** (то есть сначала заведи PayPal).
- Комиссия VGen ~5% + процессинг.
- Плюс: отзывы, очередь заказов, защита от скама — всё встроено.

### Ko-fi (как витрина / донаты)
- Работает только через PayPal или Stripe. Stripe в Казахстане, скорее всего, **недоступен** → подключай PayPal.
- Удобно: кнопка «Commissions» + донаты + магазин.

### Stripe, Wise, Payoneer
- Stripe для KZ — недоступен.
- Payoneer/Wise — можно рассмотреть позже, когда заказов станет много. На старте не нужны.

## Налоги

Доход из-за рубежа — это тоже доход. Узнай про **ИП на упрощёнке / самозанятость в Казахстане** (eGov, или спроси у знакомого бухгалтера). Пока заказов мало — хотя бы веди учёт в [`tracker/commissions.csv`](../tracker/commissions.csv).
